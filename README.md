# 🛒 বাজার দর (BazarDor)

**বাজার দর** is a responsive web application that helps users explore daily prices of essential products in Bangladesh and compare prices across different markets.

## 🛠️ Technologies Used

- Next.js & React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB Atlas
- React Hot Toast

## ✨ Features

- 📊 View daily prices of essential products.
- 📈 Track products with increasing and decreasing prices.
- 🗂️ Browse products by category.
- 🏪 Compare prices across different markets.
- 🔐 Sign in and sign up using email/password.
- 🌐 Google and GitHub social login.
- 🛡️ Protected product detail pages.
- 📱 Responsive design for mobile, tablet, and desktop.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Configure the required environment variables in `.env.local` before running the application.
